# Release v0.8.0 — Cognitive Layer

## Release Summary

CMM OS **v0.8.0** introduces the complete **Cognitive Layer (Phase 8)**, adding structured, typed, auditable, and deterministic knowledge processing capabilities to the AI-native operating runtime.

---

## Key Features

### 1. Resources & Extraction (Phases 8.2 – 8.3)
- Typed `Resource` and `ResourceInput` contracts with provenance, temporal validity, and permissions.
- Extractor and adapter registries (`ResourceAdapterRegistry`, `KnowledgeExtractorRegistry`).

### 2. Knowledge Representation & Model (Phase 8.4)
- Canonical `KnowledgeItem`, `Evidence`, `KnowledgeRelation`, `Contradiction`, `TemporalScope`, and `KnowledgeBundle`.
- Deep immutability (`frozen=True`, `slots=True`, `MappingProxyType`).

### 3. Persistent Knowledge Stores (Phase 8.5)
- `InMemoryKnowledgeStore`: Snapshot-based in-memory store with transaction rollback.
- `SQLiteKnowledgeStore` (`LocalKnowledgeStore`): ACID SQLite store with JSON payload serialization and indexed lookup.

### 4. Knowledge Retrieval & Consolidation (Phases 8.6 – 8.7)
- `KnowledgeQuery`, `KnowledgeQueryResult`, `KnowledgeRetriever`.
- `KnowledgeConsolidator` for duplicate detection, plan building, previewing, and TOCTOU-safe atomic application.

### 5. Contradiction Detection & Resolution Pipeline (Phases 8.8 – 8.12)
- Rule-based `KnowledgeContradictionDetector` for direct opposition, negation, quantitative, and temporal conflicts.
- `KnowledgeContradictionResolver` for non-mutating resolution proposals (`ContradictionResolutionProposal`).
- `ContradictionResolutionPolicyEngine` for policy authorization (`ResolutionPolicyEvaluation`).
- `ContradictionResolutionExecutor` for transactional execution with audit records (`ResolutionAuditRecord`).

### 6. Resolution Memory & Reflection (Phases 8.13 – 8.14)
- `InMemoryResolutionMemoryStore` for non-destructive decision history.
- `CognitiveReflectionEngine` for analytical reports (`CognitiveReflectionReport`, `ReflectionFinding`).

### 7. Cognitive Integration Cycle (Phase 8.15)
- `CognitiveCycleEngine` for end-to-end cycle orchestration with deterministic cycle IDs (`CognitiveCycleRecord`).

---

## Security & Cognitive Invariants

v0.8.0 enforces 12 cognitive invariants:
1. Epistemic preservation
2. Detect before resolve
3. Propose before authorize
4. Authorize before execute
5. Executor-only mutation
6. Atomic mutation
7. No silent information loss
8. Immutable contracts
9. Deterministic identity
10. Auditability
11. Reflection is descriptive
12. Agency separation

## Technical Limitations & Boundaries

- **Resolution Memory Store**: Currently in-memory (`InMemoryResolutionMemoryStore`).
- **Detection Rules**: Rule-based conservative heuristics (no vector embeddings or external LLM API calls).
- **Goal & Agency**: Reserved for Phase 9.

---

## Upgrade & Compatibility Notes

- v0.8.0 maintains full backward compatibility with v0.7.0 APIs.
- All public exported contracts support both `serialize()` / `from_mapping()` and compatibility aliases `to_dict()` / `from_dict()`.
