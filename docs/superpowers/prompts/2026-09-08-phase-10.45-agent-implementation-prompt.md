# 18. Confidence, contradiction, temporal, and epistemic invariants

These invariants are mandatory.

## Confidence

The interface layer may preserve or safely lower confidence only if canonical policy explicitly requires it.

It may never increase upstream confidence.

## Contradictions

Unresolved contradictions remain unresolved.

The interface layer may not hide or silently resolve them.

## Temporality

Superseded, invalidated, expired, denied, or canonical-upstream-excluded knowledge must not re-enter through Phase 10.45.

## Epistemic kind

Facts remain facts.

Observations remain observations.

Inferences remain inferences.

Hypotheses remain hypotheses.

Unknowns remain unknowns.

The interface boundary cannot reinterpret epistemic type.

## Causality

Correlation/dependency must never be strengthened into causation.
