# 7. MAJOR-V3-001 — Complete persisted-event safety and runtime type validation

V3 still accepts unsafe persisted header values such as:

- `metadata={"opaque": object()}`
- `metadata={"blob": b"abc"}`
- `metadata={"blob": bytearray(b"abc")}`
- `metadata={"metric": NaN}`
- `metadata={"metric": +inf}`

A metadata object whose `__str__()` returns `api_key=abcdef1234567890` can reach durable JSON because serialization can stringify opaque values.

The public path also lacks a fully enforced canonical runtime type for `sensitivity`.

Examples that must fail or be explicitly canonically normalized before persistence:

- `sensitivity=123`
- `sensitivity=None`
- `sensitivity="api_key=abcdef1234567890"`
- `sensitivity="system_prompt=TOP SECRET"`

`permissions="admin"` must not be silently coerced to a character list.

### Required RED tests

Before any production fix, reproduce:

- opaque metadata object accepted;
- bytes accepted in metadata;
- bytearray accepted in metadata;
- NaN/inf accepted in metadata;
- `SecretObject.__str__()` credential reaches/attempts to reach durable JSON;
- invalid sensitivity values accepted;
- credential-bearing sensitivity accepted;
- plain-string permissions coerced rather than rejected.

### Required implementation

Extend the existing Phase 11.22 safety/type authority.

Persisted event facts must enforce:

- content safety;
- JSON-safe descriptive types;
- finite floats;
- canonical enum/classification;
- valid structural container shapes.

Metadata must recursively reject opaque runtime objects, binary values and non-finite numbers.

Sensitivity must have one canonical runtime representation: either strict `EventSensitivity` or one explicit supported-string normalization immediately converted to that enum.

Permissions must be validated structurally before factory coercion.

Inspect equivalent persisted header fields for silent `str/list/dict` coercion.

Do not rely on `json.dumps(default=str)` as a safety mechanism.

Mandatory regression:

```python
class SecretObject:
    def __str__(self):
        return "api_key=abcdef1234567890"
```

This object in metadata must fail before durable append, and the credential string must never appear in JSONL.

# 8. MAJOR-V3-002 — Stable canonical structured payload normalization and round-trip

Safe structured payloads currently have unstable representation.

These valid payloads must publish successfully:

```python
{"result_reference": {"reference_id": "ref-1"}}
```

and:

```python
{"approval_refs": [{"approval_id": "app-1"}]}
```

V3 crashes because nested `MappingProxyType` reaches the factory deepcopy path.

Safe sequence values such as `supporting_domains` also drift:

- live: tuple
- reopened: list

The live event and reopened event must not differ in canonical shape.

A manually constructed event passed to `publish_event()` can also retain nested aliases in `PublicationResult.event`.

### Canonical shape decision

Use one stable JSON-compatible payload representation.

Recommended:

- mapping → plain dict
- sequence/array → plain list
- scalar → approved finite JSON-compatible scalar

Do not keep tuples as canonical `payload.data` arrays if durable JSON inevitably reopens them as lists.

### Required RED tests

Prove before fix:

- nested `result_reference` crashes;
- nested `approval_refs` crashes;
- `supporting_domains` differs live vs reopened;
- real `PlatformOrchestrationEventSink` round-trip differs;
- caller mutation of original nested input mutates `PublicationResult.event`.

### Required implementation

Create/reuse one recursive canonical payload normalization in the existing event safety/policy layer.

It must:

1. validate safety;
2. recursively thaw immutable validation views;
3. normalize mappings to plain dicts;
4. normalize supported sequences to plain lists;
5. deep-detach caller-owned nested containers;
6. reject opaque/binary/non-finite values;
7. feed only JSON-compatible canonical data into the event factory;
8. produce the same shape after durable reopen and replay.

`AgentRuntimeEventNormalizer.normalize()` or the Phase 11.22 public boundary must not leave shallow aliases.

Fingerprint semantics must remain deterministic.
