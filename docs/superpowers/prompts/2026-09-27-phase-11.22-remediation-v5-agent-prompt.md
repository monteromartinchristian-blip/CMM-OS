```python

```

is still treated as a descriptive sequence and canonicalized into a list of integers.

It is accepted through the public Phase 11.22 path and persisted.

The frozen rule is semantic:

```text

```



```text

```

Control cases:

```text

tuple/list of safe identifiers remains valid
```

Do not solve this by banning all sequences.

## Required implementation


# 9. MAJOR-V5-003 — DLQ safety must fail safe at the canonical bus boundary

## Audit finding

V4 correctly sanitizes unsafe exception class names when the canonical `EventSystem` composition has bound the error categorizer.

But the canonical transport itself supports:

```text
AgentRuntimeEventBus
+
canonical DLQ
+
bounded retry
```

without requiring that the categorizer has been bound.

When `_error_categorizer` is `None`, an identifier-shaped credential class name such as:

```text
api_key_abcdef1234567890
```

can be written directly into canonical DLQ `error_type` / `error`.

The safety invariant must not depend on a caller remembering an optional second binding.

## Architectural constraint

Do not import Domain policy into `cmm.agent_runtime`.

The V4 remediation correctly preserved:

```text
AGENT_RUNTIME_TO_DOMAIN_IMPORTS=0
```

That must remain true.

Do not create another DLQ subsystem.

## Required RED tests

Using canonical components directly:

```python
bus = AgentRuntimeEventBus(max_delivery_attempts=2)
dlq = InMemoryAgentRuntimeDeadLetterQueue()
bus.bind_dead_letter_queue(dlq)
```

without calling `bind_error_categorizer()`:

1. credential-shaped identifier exception class:
   ```text
   api_key_abcdef1234567890
   ```
   must currently reproduce secret retention before the fix;

2. private-marker identifier-shaped class name:
   choose a valid identifier containing a forbidden private marker;

3. normal `RuntimeError` control;

4. legacy direct bus path without bounded DLQ/retry behavior.

## Required implementation

Make the canonical bus fail safe when no categorizer is bound.

Preferred minimal invariant:

```text
DLQ/bounded-retry path
+
no external categorizer
→ neutral bounded category
```

such as:

```text
SubscriberDeliveryError
```

Do not preserve arbitrary class names in the no-categorizer case.

When the canonical composed `EventSystem` binds the safe categorizer, ordinary safe names such as:

```text
RuntimeError
```

may remain useful.

Alternative acceptable design:

```text
DLQ-enabled bounded retry cannot be activated without a categorizer
```

only if this does not break existing canonical composition or historical compatibility and is clearly supported by tests.

The neutral-default approach is preferred because it is fail-safe and minimally invasive.

## Required compatibility

Preserve:

```text
legacy direct single-attempt bus behavior
subscription invocation semantics
bounded retry attempt count
targeted DLQ replay
unrelated-subscriber isolation
DLQ retention/removal semantics
detached DLQ snapshots
```

No new reverse imports.
