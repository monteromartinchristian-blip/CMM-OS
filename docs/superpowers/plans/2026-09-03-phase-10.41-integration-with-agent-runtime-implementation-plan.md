# CMM OS — Phase 10.41 — Integration with Agent Runtime Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Connect Domain Intelligence to the canonical Phase 9 Agent Runtime so Domain resolution, composition, cognition, permissions, autonomy, budgets, operations, reevaluation, traces, and memory bindings specialize an agent execution without creating parallel runtime infrastructure.

**Architecture:** Phase 10.41 is owned by `cmm.domains`. It adds one thin Domain → Agent Runtime integration boundary that prepares and restricts an existing `IntegratedAgentExecutionRequest`, then delegates the lifecycle to `AgentRuntimeIntegrationService.execute(...)`. The dependency direction remains strictly `cmm.domains → cmm.agent_runtime`; canonical Phase 8/9/10 owners remain authoritative for cognition, execution, validation, approval, budget state, recovery, traces, and persistence.

**Tech Stack:** Python 3.10-compatible codebase, frozen/slotted dataclasses, `Protocol`, existing CMM OS Domain Intelligence contracts, Phase 8 Cognitive Layer, Phase 9 Agent Runtime, pytest, Ruff, `compileall`, Git.

- Preserve `AGENT_RUNTIME_TO_DOMAIN_IMPORTS=0` throughout implementation.

- `ActionBudgetService` is the only mutable budget owner. Domain code may only restrict existing limits through the canonical decrease/restriction path; it must never request or perform a Domain-driven increase.

- Phase 10.40 `DefaultDomainCognitiveIntegrator` remains the Domain-to-Cognitive owner; no second Cognitive Layer is permitted.

```python
from __future__ import annotations

import ast
from pathlib import Path


def imports_prefix(root: Path, prefix: str) -> list[tuple[Path, str]]:
    found: list[tuple[Path, str]] = []
    for path in sorted(root.rglob("*.py")):
        tree = ast.parse(path.read_text(encoding="utf-8"))
        for node in ast.walk(tree):
            if isinstance(node, ast.Import):
                for alias in node.names:
                    if alias.name == prefix or alias.name.startswith(prefix + "."):
                        found.append((path, f"import {alias.name}"))
            elif isinstance(node, ast.ImportFrom):
                module = node.module or ""
                if module == prefix or module.startswith(prefix + "."):
                    found.append((path, f"from {module} import ..."))
    return found
```
