# Phase 10.42 — Planner and Workflow Engine Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate Domain Intelligence with the canonical Phase 9 planning path and shared Workflow Engine so plans can use registered, available, permission-compatible Domain operations and workflows without creating incompatible nodes or parallel owners.

**Architecture:** Add one Domain-owned coordination boundary that projects current Domain capabilities into existing `AgentPlanningRequest` / `AgentWorkflowPlan` contracts, keeps `AgentPlanningService` and `TaskPlanner` as the sole planning owners, reuses the Phase 10.41 operation dispatch path, and delegates Domain workflows to `DomainWorkflowExecutor` backed by the shared `WorkflowEngine`. One minimal generic Phase 9 seam is permitted: deterministically carrying `workflow_references` from existing planning metadata into `AgentWorkflowPlan.metadata`; Phase 9 must remain completely Domain-agnostic.

**Tech Stack:** Python repository `.venv`, dataclasses / immutable contracts, `typing.Protocol`, pytest, Ruff, canonical CMM OS Domain registries/resolver/composer/permissions, Phase 9 Agent Runtime planner contracts, shared `WorkflowEngine`.

def imports_from(root: Path, prefix: str) -> list[tuple[str, str]]:
    hits: list[tuple[str, str]] = []
