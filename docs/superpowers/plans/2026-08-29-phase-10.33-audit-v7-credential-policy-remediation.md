## 3. Canonical Policy Interface

### Module: `cmm/domains/credential_policy.py`

```python
@dataclass(frozen=True, slots=True)
class CredentialSignature:
    name: str
    pattern: re.Pattern[str]

HIGH_CONFIDENCE_CREDENTIAL_SIGNATURES: tuple[CredentialSignature, ...]

def contains_high_confidence_credential(value: str) -> bool:
    """Return True when value contains a recognized high-confidence credential."""
```

16. `dockerhub_pat` (Docker Hub PAT: `dckr_pat_...`)
17. `authorization_header` (Authorization Header assignments)
18. `bearer_token` (Bearer token formats)
19. `bearer_assignment` (Bearer token assignments)
20. `credential_assignment` (Structured credential assignments)

### Design Constraints

- Deterministic, precompiled regexes only (`re.search`).
- Unique signature names.
- Zero network dependencies, zero 3rd-party scanning dependencies, zero entropy analysis.
- No generic long-string, JWT, UUID, or base64 heuristic rejections to prevent false positives.

## 5. Regression Matrix

Table-driven fixture matrix: `credential family` ×
- `event_id`
- `reference_id` (constructor and `from_dict`)
- `payload` nested value
- `metadata` nested value
- `session_id`
- `correlation_id`
- `causation_id`
- `actor`
- `permissions`
- `DomainId` (e.g. `glpat-...` slug)
- `factory` (`create_event`)
- `from_dict` (`DomainEvent.from_dict`)
- `Kernel publication` (`DomainKernelEventPublisher.publish` -> 0 emitted events)

Invariants:
- `credential not in str(exc)` and `credential not in exc.details`.
- Policy self-tests: unique names, compile check, positive detection, safe near-miss non-detection, UUID/URL/ID/slug non-detection.
