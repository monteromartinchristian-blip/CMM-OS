- [ ] **Step 8: Implement exact canonical Decimal text from `as_tuple()`**

Implement context-free logic based on:

```python
sign, digits, exponent = value.as_tuple()
```

Required algorithmic behavior:

```text
if numeric value == 0:
    return "0"

coefficient = exact digit sequence

if exponent >= 0:
    append exponent zeros
    return fixed-point integer text

if exponent < 0:
    decimal_position = len(digits) + exponent

    if decimal_position > 0:
        insert decimal point inside coefficient
    else:
        prefix "0." plus the required leading zeros

strip only insignificant trailing fractional zeros
strip a terminal decimal point
preserve all significant coefficient digits
never call normalize()
never convert to float
never depend on getcontext().prec
```

Because valid benchmark costs are non-negative, sign handling may assert/reject negative non-zero values through the existing validator; negative zero must canonicalize to `"0"`.
