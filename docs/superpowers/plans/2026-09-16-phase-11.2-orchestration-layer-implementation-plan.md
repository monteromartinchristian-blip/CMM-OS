# CMM OS — Phase 11.2 Orchestration Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement one fail-closed global request Orchestration Layer that coordinates existing canonical CMM OS subsystems without duplicating their ownership.

**Architecture:** Add a new `cmm/orchestration/` package above the closed Phase 11.1 composition core. The new Orchestrator resolves deterministic request intent, gathers authorized context, delegates domain selection to canonical Domain Intelligence, chooses an execution path while delegating agent selection to canonical Agent Runtime authority, applies restrictive policy, records safe orchestration decisions, emits safe lifecycle events, and returns immutable structured results. Phase 11.2 does not execute the full downstream operation/workflow/agent vertical and does not implement the Phase 11.3 Application Backend.

**Tech Stack:** Python 3.10+, frozen dataclasses/enums/protocols, existing `cmm.platform` composition contracts, `cmm.domains`, `cmm.agent_runtime`, `cmm.runtime.sessions`, pytest, Ruff, compileall, git archive.

**Spec:** `docs/superpowers/specs/2026-09-16-phase-11.2-orchestration-layer-design.md`

**Inspection basis:** `cmm-phase11-2-orchestration-layer-readonly-inspection-20260916-013044.txt`

**Starting branch:** `feature/phase-11-stable-integrated-platform`

**Starting HEAD:** `b3aa5e3b8a7538874cbeba91030417bf4859feeb`

**Requirement:** `F11-016 — Canonical Request Orchestration`

**Design Point:** `DP-102 — Fail-Closed Canonical Request Orchestration Pipeline`

**Acceptance:** `AT-DP-102 — Connected Orchestration Acceptance`

## Global Constraints

- Phase 11.1 is closed and must remain closed.
- Phase 11.34 Provider Registry is closed and must remain closed.
- `cmm/orchestration` is the only new Phase 11.2 production package.
- Phase 11.2 coordinates canonical owners; it does not replace them.
- Domain selection remains owned by `cmm.domains.resolver.DefaultDomainResolver`.
- Agent compatibility/selection remains owned by `cmm.agent_runtime.agent_registry_service.AgentRegistryService` / `cmm.agent_runtime.agent_resolver.AgentResolver`.
- Canonical session authority remains `cmm.runtime.sessions.SessionStore`.
- Agent execution remains owned by `AgentRuntimeIntegrationService`.
- Workflow execution remains owned by `cmm.workflows`.
- Operation execution remains owned by `cmm.execution` and existing Domain operation orchestration.
- Validation remains owned by `cmm.validation`.
- Provider/model routing remains outside Phase 11.2.
- No new Provider Registry, Domain Registry, Agent Registry, Session Store, workflow engine, execution engine, validation engine, Memory Store, Knowledge Store, Event Bus, planner, model router or general policy engine.
- No API, HTTP server, application-service facade, OpenAPI, streaming, pagination or API idempotency; those are Phase 11.3.
- No CMMChat/CMM Bots integration.
- No Model Gateway dependency.
- No hidden model call from IntentResolver.
- No hidden chain-of-thought or raw reasoning in public contracts, events, decisions or errors.
- No downstream operation/workflow/agent execution inside the Phase 11.2 Orchestrator.
- Decision persistence and safe event emission are the only Phase 11.2-owned side effects.
- Supporting domains may never widen permissions or lower sensitivity.
- Canonical deny/approval requirements can never be widened to allow.
- All public orchestration values are immutable, validated and serialization-safe.
- Normal request handling uses constructor injection, not `ApplicationContainer` as a runtime service locator.
- Every block follows `TEST RED → MINIMAL IMPLEMENTATION → GREEN → CONTROLLED REFACTOR`.
- Do not weaken inherited tests.
- Do not run `git push`, `git merge`, `git stash`, `git reset`, `git clean` or `git worktree`.
- Preserve the quarantine stash.
- Before audit the maximum state is `IMPLEMENTED_PENDING_INDEPENDENT_AUDIT`.
