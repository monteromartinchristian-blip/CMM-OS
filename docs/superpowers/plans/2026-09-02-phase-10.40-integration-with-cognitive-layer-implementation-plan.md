# Phase 10.40 — Integration with Cognitive Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a thin, one-way Domain Intelligence → Phase 8 Cognitive Layer integration boundary that adapts already-resolved Domain profiles/resources/rules into existing cognitive contracts, executes cognition only through canonical Phase 8 owners, and then feeds canonical evidence into existing Domain presentation and trace infrastructure.

**Architecture:** Add two focused Domain-side modules: immutable integration contracts and a small `DefaultDomainCognitiveIntegrator`. The integrator reuses Phase 8 `ResourceAdapterRegistry`, `KnowledgeExtractorRegistry`, `materialise_result`, `KnowledgePackageBuilder`, `CognitiveValidator`, `ReasoningRuleContext`, and the existing Domain rule selector/executor, presentation planner, and trace contracts. It never creates a cognitive engine/store/graph/question engine/confidence engine/session store, never imports Agent Runtime, and never introduces a dependency from `cmm.cognitive` to `cmm.domains`.

**Tech Stack:** Python 3.10+, frozen slotted dataclasses, existing `cmm.cognitive` Phase 8 contracts/services, existing `cmm.domains` contracts/services, pytest >=9,<10, Ruff >=0.9,<1, `git archive`.

    tree = ast.parse(path.read_text(encoding="utf-8"), filename=str(path))
    for node in ast.walk(tree):
        if isinstance(node, ast.ImportFrom):
