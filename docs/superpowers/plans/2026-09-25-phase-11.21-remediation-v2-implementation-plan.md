# PART II — MINIMUM FIX

## 9. Remove/narrow the global AUTO egress precheck

Current residual behavior is caused by a candidate-set-wide check before AUTO iteration.

The implementation must eliminate the semantic:

```text
if any AUTO candidate is remote and privacy authority/metadata is absent:
    reject whole AUTO request
```

Preferred fix:

```text
remove global AUTO egress precheck
```

and rely on the existing candidate-specific privacy gate during AUTO iteration.

Alternative:

```text
narrow precheck so it is only terminal when every viable candidate requires remote egress
```

Only use the alternative if it is demonstrably simpler and does not duplicate candidate logic.
