1. keep the failing test;
2. label the requirement `GAP_RED` in the implementation notes;

4. modify that owner only;

6. run that owner's historical regression suite;
7. commit the correction with a narrow `fix(domains): ...` commit;
8. do not create a new owner or generic 10.51 runtime.
