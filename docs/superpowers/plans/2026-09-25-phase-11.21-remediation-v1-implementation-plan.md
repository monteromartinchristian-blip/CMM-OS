## 14. Implement bounded provider-event pump

```text

```

```text

```

## 15. Public stream state machine

Public iterator remains authoritative for:

```text
deadline
cancellation
normalization
terminal event
dropping late events
```

Once terminal:

```text
ignore all later queued events
return immediately
```

No event after timeout/cancel may reach public consumers.

## 16. Timeout vs cancellation

Preserve distinct semantics:

```text
user cancellation -> CANCELLED
deadline expiration -> ERROR(PROVIDER_TIMEOUT)
```

Timeout may signal/cancel the cooperative provider token for cleanup, but public status remains timeout.
