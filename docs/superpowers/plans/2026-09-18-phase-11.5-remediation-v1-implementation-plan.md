## 4.1 RED — public caller cannot pass raw Domain visibility

```text

```

```text

regenerate
```

A bare `ConversationalDomainView` must not be a per-call public argument.

HTTP models remain closed and continue to reject domain projection input.

## 4.2 Introduce read-only source protocol

Add one protocol, conceptually:

```python
class AuthorizedDomainProjectionSource(Protocol):
    def get_projection(
        self,
        *,
        request_id: str,
        session_id: str,
        application_response: ApplicationResponse,
    ) -> DomainInterfaceProjection | None:
        ...
```

The exact method name may follow repository conventions.

The protocol:

- stores nothing;
- resolves nothing;
- composes nothing;
- grants nothing;
- mutates nothing.

It is injected at `ConversationService` construction.

## 4.3 Official test implementation

Tests may define an in-memory/fake source in test code.

Do **not** create a production in-memory projection registry unless an already canonical Phase 10.45 official in-memory implementation exists and can be reused.

## 4.4 Mandatory binding verifier

Add RED tests for all mismatches:

```text
projection.request_id != application_response.request_id
projection.request_id != current request_id
projection.session_reference_id != current session_id
application_response.data["session_id"] != current session_id
projection.conversational is None
projection.conversational.primary_domain != application_response.data["primary_domain"]
projection.conversational.supporting_domains != application_response.data["supporting_domains"]
projection.resolution_reference_id not bound to canonical same-request route evidence
```

Each mismatch:

```text
fails closed
exposes zero domain refs
persists no assistant response containing foreign refs
```

Use the Phase 10.45 `DomainInterfaceProjection` contract directly.

Do not duplicate its content-digest algorithm.

## 4.5 Resolution reference binding

Before implementation, identify the existing canonical Domain-resolution trace reference emitted by real Phase 11.2 orchestration.

Add a focused test that extracts the same canonical reference from the actual application/orchestration result and compares it to:

```text
projection.resolution_reference_id
```

Do not generate a second resolution reference inside `cmm.conversation`.

If the necessary canonical reference is not present in the existing `ApplicationResponse`, an **additive safe field projection** from the existing Orchestration result through `RequestApplicationService` is allowed.

If this is necessary, touch only:

```text
cmm/application/requests.py
```

and its direct contract/regression tests.

Do not expose raw trace payloads; expose only the authorized reference string already present in the canonical orchestration result.

## 4.6 Projector signature

The projector must receive either:

```text
DomainInterfaceProjection | None
```

or a service-validated `ConversationalDomainView` that is impossible to obtain before provenance validation.

Preferred order:

```text

→ service verifies provenance
→ projector consumes projection.conversational
```

The projector itself remains side-effect-free.

## 4.7 No projection source

When no canonical source is composed:

```text

```

and Domain output remains empty.

Do not reconstruct from application data.

## 4.8 Cross-session adversary
