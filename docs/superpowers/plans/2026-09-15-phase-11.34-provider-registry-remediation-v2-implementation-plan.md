**Goal:** Close exactly the five findings from Phase 11.34 Independent Re-audit V2 while preserving the canonical Provider Registry architecture and all behavior already verified by Remediation V1.

**Architecture:** Keep `ProviderRegistry` as the sole provider identity authority; make manifest metadata visibility depend on the exact canonical `ProviderSpec` instance; introduce one focused `ProviderRegistryStateCoordinator` for Provider Registry revision/audit persistence; make isolation an explicit provider-manifest policy; make new-connection onboarding reject pre-existing credential/profile resources before mutation; and add a dedicated Phase 11 requirements/reference matrix with `F11-014` → `DP-134` → `AT-DP-134` traceability. No general transaction framework, no parallel registry/runtime, and no CMM Usage/CMMChat integration is allowed.

**Tech Stack:** Python 3.10+, pytest, dataclasses, pathlib, existing Provider Registry contracts, existing `ProviderRegistryStateRepository`, Ruff/format, `compileall`, git archive.

def _active_manifest(self, provider_id: str) -> ProviderManifest | None:

    return binding.manifest
