- [ ] **Step 3: Replace lifecycle-only persistence with pre/post mutation detection**



Build existing lifecycle records exactly as before.

Then derive refresh-only records from pre/post route state.

A route qualifies for `route.refreshed` only if:

```text

route exists after
route not in new_route_ids
route not in restored_route_ids
route not in unavailable transition ids
before.available is True
after.available is True

```

```python
self._audit_record(
```
