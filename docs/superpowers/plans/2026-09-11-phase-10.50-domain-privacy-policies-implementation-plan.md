# Phase 10.50 — Domain Privacy Policies Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement Phase 10.50 Domain Privacy Policies as immutable, declarative Domain-owned defaults that project into the canonical Phase 8 `PrivacyMetadata` system, attach to the canonical `DomainDefinition` / Domain Pack path, cover all 12 current first-party Domains, preserve Phase 10.15 permission authority, and satisfy connected `AT-DP-050` without creating parallel privacy infrastructure.

**Architecture:** Add one small Domain contract module, one additive `DomainDefinition.privacy_policy` field, one pure projection helper to canonical `PrivacyMetadata`, first-party policy declarations, and one safe reference-only Domain Trace extension. All effective privacy resolution and operation evaluation remain owned by `cmm.cognitive.privacy.resolve_effective_privacy_metadata(...)` and `evaluate_privacy_operation(...)`. Cross-domain authority remains owned by existing Phase 10.15 permission infrastructure.

**Tech Stack:** Python 3, frozen/slotted dataclasses, canonical CMM OS Domain contracts, Phase 8 Cognitive privacy contracts, Phase 10.15 permission contracts, pytest, Ruff, `compileall`, Git.

The implementation must inspect the exact current constructor/serialization signatures before editing and must preserve them. It must not redefine any consumed type.

### Produces

Phase 10.50 produces exactly this new conceptual Domain contract surface:

```python
@dataclass(frozen=True, slots=True)
class DomainPrivacyPolicy:
    schema_version: str
    domain_id: DomainId
    default_privacy: PrivacyMetadata
    require_approval_for_remote: bool = False
    metadata: Mapping[str, JsonValue] = field(default_factory=dict)
```

and one pure projection helper equivalent in responsibility to:

```python
def project_domain_privacy_metadata(
    policy: DomainPrivacyPolicy,
    *,
    processing_location: ProcessingLocation,
) -> PrivacyMetadata:
    ...
```

The helper may only project the Domain declaration into canonical `PrivacyMetadata`. It is not an effective-policy resolver and is not an operation evaluator.

`DomainDefinition` gains one additive final field:

```python
privacy_policy: DomainPrivacyPolicy | None = None
```

No other new authority contract is permitted.
