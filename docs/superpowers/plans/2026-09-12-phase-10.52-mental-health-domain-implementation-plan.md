## Global Constraints

- Phase 10.51 is closed and remains immutable except for ordinary regression-compatible imports/public export wiring required by 10.52.
- Phase 10.53 remains `NOT_STARTED`; `cmm/domains/neurodivergence/` must not be created by this phase.
- Canonical identity is exactly `domain:mental-health`.
- Canonical profile is exactly `MentalHealthProfile`.
- Design Point is `DP-052 — Mental Health Domain Specialization`.
- Connected acceptance is `AT-DP-052 — Connected Mental Health Domain Journey`.
- Default Mental Health sensitivity is canonical `SENSITIVE`; do not invent a new privacy enum or a `PrivacyPolicy.SENSITIVE`.
- Health remains authoritative for documented diagnosis status, treatment, medication, medication changes, clinical medical records, and medical safety.
- Mental Health owns emotional/therapeutic specialization, not clinical medical truth.
- Ordinary emotional conversation must not default to clinical or diagnostic presentation.
- Sensitive inference discussion does not authorize persistence.
- Reading sensitive memory does not authorize proposing, approving, or applying a new memory.
- All persistence uses the existing proposal-first canonical memory path.
- Cross-domain data transfer must be purpose-minimized, provenance-preserving, temporally valid, permission-filtered, and privacy-filtered.
- Relationships remains authoritative for relationship facts; Reflection for general reflective structure; Concerns for concern organization; General remains the fallback.
- Mental Health may consume authorized Health projections but may never rewrite Health-owned diagnosis/treatment/medication truth.
- Therapy transcript handling must preserve speaker identity, source/provenance, uncertainty, and epistemic status.
- Repeated thought or rumination must not silently become diagnosis or disorder attribution.
- Safety escalation must be proportionate and must not convert ordinary distress into emergency framing.
- No autonomous external communication for sensitive Mental Health content.
- Operations are declarative and unavailable by default unless canonical implementations are explicitly injected.
- Domain workflows execute only through the existing shared workflow machinery.
- Domain operations execute only through the existing canonical operation execution path.
- No new provider/model router, Model Gateway, response renderer, Communication Profile, UI, API platform layer, or other Phase 11 infrastructure.
- No push or merge.
- Do not use `git stash`, `git stash pop/apply/drop`, `git reset`, `git clean`, or `git worktree`.
- Preserve the quarantine stash exactly.
- Every implementation task follows `TEST RED → MINIMAL IMPLEMENTATION → GREEN → CONTROLLED REFACTOR → NEXT BLOCK`.
- A failed focused test or regression is fixed before starting the next task.
- Before audit, all implementation and documentation changes are committed and the worktree is clean.
- Before audit the phase state is only `PHASE10_52=IMPLEMENTED_PENDING_INDEPENDENT_AUDIT`; never write `PHASE10_52=CLOSED` or `CLOSURE_ELIGIBLE=YES`.
