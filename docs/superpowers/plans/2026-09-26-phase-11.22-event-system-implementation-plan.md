---

## 1. Mission

Implement Phase 11.22 as an integration and hardening layer over the existing Phase 9 event infrastructure.

The implementation must not build a new event system.

The canonical transport remains:

`cmm.agent_runtime.AgentRuntimeEventBus`

The canonical registry remains:

`AgentRuntimeEventRegistry`

The canonical repository contract remains:

`AgentRuntimeEventRepository`

The canonical replay owner remains:

`AgentRuntimeEventReplayer`

The canonical dead-letter family remains the existing runtime-event DLQ contracts and implementation.

The implementation must make that existing infrastructure platform-usable by adding only the missing capabilities required by the Phase 11.22 specification.

---

## 2. Frozen architectural constraints

The agent must preserve all of the following.

### 2.1 No parallel authorities

Do not introduce:

- a second event bus;
- a second mutable event registry;
- a second repository protocol;
- a second replay engine;
- a second DLQ authority;
- a command bus;
- a broker abstraction;
- a generic event-store framework;
- a generic persistence framework;
- a service locator;
- a second application container.

### 2.2 Existing subsystem ownership remains intact

Do not redefine:

- Agent Runtime lifecycle authority;
- Domain Event authority;
- Validation lifecycle authority;
- Orchestration routing authority;
- Workflow state authority;
- Application Backend command authority;
- Provider/Model selection authority.

Phase 11.22 transports and projects lifecycle facts. It does not become their source of truth.

### 2.3 Closed-phase contracts are compatibility gates

The following already-closed phases are inherited constraints:

- Phase 7 Continuous Validation;
- Phase 9 Autonomous Agent Runtime;
- Phase 10.33 Domain Events;
- Phase 11.1 Integration Core;
- Phase 11.2 Orchestration Layer;
- Phase 11.3 Application Backend;
- Phase 11.4 CLI;
- Phase 11.5 Conversational Interface;
- Phase 11.21 Model Gateway;
- Phase 11.34 Provider Registry;
- Phase 11.50 Reusable Backend Interfaces.

No existing public contract may be renamed, removed or semantically weakened.
