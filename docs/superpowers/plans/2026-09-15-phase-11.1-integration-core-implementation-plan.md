> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build one version-aware, fail-closed platform composition root that assembles existing canonical CMM OS subsystems without duplicating their registries, runtimes, stores, planners, provider authority, or orchestration behavior.

**Architecture:** Add a thin `cmm.platform` package that owns only platform-level service bindings, dependency/compatibility validation, strict composition configuration, readiness, safe inspection, and modular contribution. Existing Phase 0–10 subsystems and the closed Phase 11.34 Provider Registry remain authoritative; Phase 11.1 holds references to them and validates the graph around them.

## Global Constraints

- Preserve one shared kernel, Cognitive Layer, Agent Runtime, domain system, validation system, and memory/knowledge architecture.
- Do not create a second Provider Registry or alter the closed `DP-134` ownership model.
- Do not create another executable Tool Registry, planner, workflow engine, event bus, store, runtime, or domain resolver.
- Do not implement Phase 11.2 Orchestrator, Intent Resolver, Context Resolver, Domain Router, Agent Router, API, conversational flow, or CMMChat integration.
- `IntegrationServiceRegistry` registers platform composition bindings only; it does not register providers, agents, workflows, operations, rules, validators, or domains themselves.
- Existing canonical object instances are referenced, not cloned into new platform-owned state.
- All new public platform values are immutable and serialization-safe.
- Unknown/malformed contract versions, missing required dependencies, cycles, duplicate authorities, invalid replacements, and invalid configuration fail closed.
- Exact schema-version compatibility is the default compatibility rule.
- No network lookup, plugin discovery, import-time mutation, secret loading, or hidden side effects are allowed in composition validation.
- Production replacement is allowed only before readiness; a ready container is immutable by default.
- Test adapters use the same explicit binding API as production implementations.
- No push, merge, stash, reset, clean, or worktree operations are part of implementation.
- Preserve the quarantine stash untouched.
- Every task follows `TEST RED → MINIMAL IMPLEMENTATION → GREEN → CONTROLLED REFACTOR`.
- A newly introduced regression must be fixed before moving to the next task.
- Before audit, implementation and documentation must be fully committed and the worktree clean.

```python
    normalized = value.strip()

class ContractClassification(str, Enum):
```

- [ ] **Step 6: Implement `ServiceDependency`, `ServiceDescriptor`, and `ServiceBinding` minimally**

Required semantics:

```python
@dataclass(frozen=True, slots=True)
class ServiceDependency:
    service_id: str
    contract: ContractMetadata

    def __post_init__(self) -> None:
        object.__setattr__(self, "service_id", _non_empty(self.service_id, "service_id"))


@dataclass(frozen=True, slots=True)
class ServiceDescriptor:
    service_id: str
    contract: ContractMetadata
    implementation_id: str
    dependencies: tuple[ServiceDependency, ...] = ()
    mode: ServiceMode = ServiceMode.LOCAL
    authority: str | None = None
    metadata: Mapping[str, Any] = field(default_factory=dict)

    def __post_init__(self) -> None:
        service_id = _non_empty(self.service_id, "service_id")
        implementation_id = _non_empty(self.implementation_id, "implementation_id")
        dependency_ids = tuple(dep.service_id for dep in self.dependencies)
        if service_id in dependency_ids:
            raise ValueError("service cannot depend on itself")
        if len(set(dependency_ids)) != len(dependency_ids):
            raise ValueError("dependency service IDs must be unique")
        authority = self.authority.strip() if self.authority is not None else None
        if authority == "":
            raise ValueError("authority must be non-empty when provided")
        object.__setattr__(self, "service_id", service_id)
        object.__setattr__(self, "implementation_id", implementation_id)
        object.__setattr__(self, "authority", authority)
        object.__setattr__(self, "dependencies", tuple(sorted(self.dependencies, key=lambda item: item.service_id)))
        object.__setattr__(self, "metadata", MappingProxyType(dict(self.metadata)))


@dataclass(frozen=True, slots=True)
class ServiceBinding:
    descriptor: ServiceDescriptor
    implementation: object
    runtime_contract: type[Any] | None = None
```

Do not store secrets or copied subsystem state in descriptors.

```python
from dataclasses import dataclass

from cmm.platform.contracts import ContractMetadata


@dataclass(frozen=True, slots=True)
class CompatibilityResult:
    compatible: bool
    reason_code: str


def check_contract_compatibility(
    required: ContractMetadata,
    provided: ContractMetadata,
) -> CompatibilityResult:
    if required.contract_name != provided.contract_name:
        return CompatibilityResult(False, "CONTRACT_NAME_MISMATCH")
    if required.owner != provided.owner:
        return CompatibilityResult(False, "OWNER_MISMATCH")
    if required.schema_version != provided.schema_version:
        return CompatibilityResult(False, "SCHEMA_VERSION_MISMATCH")
    if required.contract_version != provided.contract_version:
        return CompatibilityResult(False, "CONTRACT_VERSION_MISMATCH")
    return CompatibilityResult(True, "EXACT_MATCH")
```

Do not implement semver ranges, migration, downgrade, coercion, or remote compatibility lookup in 11.1.
