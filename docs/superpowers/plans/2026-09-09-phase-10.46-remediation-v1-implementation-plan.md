> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remediate only Independent Audit V1 MAJOR-01 and MAJOR-02 by making Domain premium participation neutral and making the import-safe Domain policy adapter semantically fail-closed, then strengthen AT-DP-046 and return Phase 10.46 to an audit-ready pending-verification state.

**Tech Stack:** Python 3, immutable dataclasses, Agent Runtime model-requirements contracts/resolver, canonical `ModelFallbackPolicy`, pytest, Ruff.
