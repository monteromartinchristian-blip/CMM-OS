> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close exactly `MAJOR-V5-01` and `MAJOR-V5-02` by rejecting stale connection authority before any discovery I/O, preventing new route bindings under stale provider authority, and deriving a restart-stable discovery watermark from existing route timestamps plus persisted route audit history.

```python
def _latest_route_audit_at(
    self,
    connection_id: str,
) -> datetime | None:
    timestamps = []

    for record in self._audit_log:
        if record.event_type not in _DISCOVERY_ROUTE_EVENTS:
            continue

        detail = dict(record.detail)
        if detail.get("connection_id") != connection_id:
            continue

        timestamps.append(record.occurred_at)

    return max(timestamps, default=None)
```
