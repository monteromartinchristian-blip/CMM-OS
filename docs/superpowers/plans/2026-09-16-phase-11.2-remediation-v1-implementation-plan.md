> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remediate exactly the two Phase 11.2 Audit V1 MAJOR findings by making orchestration runtime roles discriminating and enforcing canonical agent-selection authority, without widening scope or reopening closed phases.

**Architecture:** Replace the ambiguous `route(...)` runtime role collision with explicit `route_domain(...)` and `route_agent(...)` protocol methods, validate all seven Orchestrator collaborators at construction time, and enforce canonical owner types for agent/domain/session collaborators where those collaborators represent source-of-truth authority.
