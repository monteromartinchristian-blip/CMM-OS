# 5. MAJOR-01 design ruling — no public live-owner escape hatch

The first-party public `ClientBackend` surface must not return live authority-bearing canonical owners.

Remove or otherwise make unavailable as public client API:

```text
ClientBackend.gateway
ClientBackend.conversation
```

if they return live:

```text
ApplicationGateway
ConversationService
```

A first-party client using only public Phase 11.50 exports must not be able to obtain:

```text
ApplicationGateway.handle
ConversationService submit/edit/regenerate/cancel/load authority
```

except through the frozen `ClientBackend` operations.

---

# 6. ConversationService accessor ruling

The audited implementation added read-only accessors such as:

```text
ConversationService.gateway
ConversationService.capability_resolver
```

Remediation must inspect whether either accessor existed solely to support Phase 11.50 identity/capability tests.

If an accessor exposes live downstream authority and is not an independently closed canonical public contract, remove it or narrow it.

The preferred design is:

```text
ClientBackend receives exact owners at construction
ClientBackend delegates privately
acceptance proves exact delegation through observable canonical state/effects
no public owner-returning accessor is needed
```

Do not replace a public escape hatch with a differently named public escape hatch.

# 13. MAJOR-03 design ruling — preserve canonical safe failure identity

Phase 11.50 client-specific error codes remain reserved for Phase 11.50 interface failures:

```text
UNSUPPORTED_INTERFACE_VERSION

INVALID_CLIENT_CONTRACT
INTERNAL_CLIENT_ERROR
```

# 14. Canonical failure projection

Real client paths must preserve/project safe canonical failure identity from:

```text
ApplicationError
ConversationErrorCode / canonical conversation exception types
```

At minimum the client-visible result must preserve:

```text
canonical safe code
canonical safe message
```

where the canonical owner already provides a safe public message.

Examples include:

```text
NOT_FOUND / RESOURCE_NOT_FOUND
CONFLICT / SESSION_CONFLICT
CAPABILITY_UNAVAILABLE
POLICY_DENIED
APPROVAL_REQUIRED
CANCELLED
INVALID_REQUEST
UNSUPPORTED_VERSION
```

Use the exact existing canonical names where available.

Do not invent a second semantic taxonomy.

# 25. MAJOR-05 design ruling — public wrappers serialize to JSON-native values

Every public wrapper claiming `to_dict()` must return only JSON-native / primitive-safe structures.

Allowed output value classes:

```text
None
bool
int
float
str
list
dict[str, primitive-safe]
```

No Python dataclass instance may survive in a `to_dict()` result.

No Enum instance may survive.

No tuple may survive.

No bytes/callable/arbitrary object may survive.

---
